# Capstone 1: Business Analysis with SQL & Excel

## Project Overview
This project analyzes sales data for EmporiUm, a fictional student bookstore and online retailer. Using SQL and Microsoft Excel, I evaluated sales performance, identified purchasing patterns, and developed business recommendations.

## Sales Territory
Oregon -- Online Sales

## Tools Used
- MySQL Workbench
- SQL
- Microsoft Excel
- Git and GitHub

## Project Analysis
- Calculated total revenue, transaction volume, and the date range for Oregon.
- Analyzed monthly and yearly revenue trends.
- Compared Oregon's online revenue with the West Region.
- Evaluated monthly transactions and average transaction amounts by product category.
- Ranked online sales revenue by state.
- Developed a recommendation for the next quarter.

## Excel Visualization
Created an Excel PivotChart comparing Oregon's monthly online sales revenue across 2022–2025.

**Workbook**: `agbozo_territory_chart.xlsx`

## Business Recommendation
Prioritize Oregon's online sales growth through targeted promotions, category-specific strategies, and campaigns aligned with monthly purchasing patterns. Use California and Washington as benchmarks to identify opportunities for improvement.

## Project Files
- `agbozo_sales_analysis.sql` — SQL analysis script.
- `agbozo_territory_chart.xlsx` — Excel PivotChart workbook.
- `README.md` — Project documentation.
